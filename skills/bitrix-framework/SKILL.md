# Канон Bitrix Framework

Baseline: main 23.0+ · Verified: main 26.1000.0

1. Определи контур: CMS, коробка или облако. Для облачного REST — `bitrix24-rest-api`; PHP-ядра там нет.
2. Перед PHP-кодом прочитай `bitrix/modules/main/classes/general/version.php` (`SM_VERSION`); для модульного API — `<module>/install/version.php`.
3. Выбери профильный скилл по задаче. В его таблице открой только нужный `rules/*.md`; соседние темы — по необходимости. Уже прочитанный канон повторно не загружай.
4. Сверяй спорный API с кодом ядра. Без исходников используй подтверждённый API и укажи ограничение проверки.

| Когда нужна подробность | Прочитай |
| --- | --- |
| `Since`, совместимость, минимальные версии | `rules/versions.md` |
| DI, ServiceLocator, конструкторы, границы слоёв | `rules/di.md` |

## Общие правила

- Свой код размещай в `/local/`; ядро `/bitrix/` не правь. Сохраняй структуру проекта, не добавляй лишние слои.
- Используй D7. Legacy допустим, когда нужного D7 API нет; укажи причину в комментарии.
- Контроллер, компонент и обработчик вызывают сервис; доступ к данным держи в сервисе/репозитории через ORM. Типизируй сигнатуры, в целых PHP-файлах добавляй `declare(strict_types=1)`.
- Перед классами модуля загружай его через `Loader::includeModule()` / `requireModule()`. Ожидаемые ошибки между модулями передавай через `Result`/`Error`.
- Сохраняй стандартные AJAX-фильтры Authentication, HttpMethod, Csrf и проверяй права отдельно. Ввод получай через Request, сессию — через Application; поля запросов разрешай белым списком, вывод экранируй.
- Секреты храни в окружении или `.settings.php`. Не помещай их в код, опции, миграции и логи.
- `/local/.settings.php` целиком заменяет `/bitrix/.settings.php`: сохрани все нужные секции. Новые маршруты — `/local/routes/*.php` (`bitrix-routing`).
- Таблицы, события и агенты модуля — в его установщике (`bitrix-modules`); данные и настройки проекта — в `sprint.migration` (`bitrix-sprint-migration`). Если его нет, предложи установку, не изобретай фреймворк миграций.

## Проверка перед завершением

- [ ] API и `Since` совместимы с версиями проекта.
- [ ] Права, ввод и вывод проверены; секреты не раскрыты.
- [ ] Кеш сбрасывается при записи; события и агенты снимаются при удалении модуля.
- [ ] В боевом окружении `exception_handling.debug = false`.
