# Интернет-магазин (`sale`)

Baseline: main 23.0+ · Verified: sale 26.600.0, main 26.1000.0

Перед PHP-кодом прочитай `bitrix-framework`, если ещё не читал его в этой задаче. По таблице открой только нужный файл правил.

`sale` управляет корзиной, заказами, оплатами, отгрузками, скидками, статусами и историей. Товары, цены, остатки: `bitrix-catalog`.

| Списки, архив, компоненты, изменения поведения | `rules/archive-components.md` |

## Общие правила

- `Loader::includeModule('sale')`; также `catalog` для товаров, цен и резерва.
- Меняй заказ объектной моделью (`Order` и коллекции), один `save()` на операцию. `Internals\*Table` для данных заказа — только чтение. Не вызывай `Order::load()` в цикле списка.
- Объектный API не проверяет права: перед запросом пользователя проверяй `CSaleOrder::CanUserViewOrder()` и соответствующие методы.
- Выбирай оплату и доставку из списков с ограничениями; не доверяй ID запроса.
- Проверяй `isSuccess()` **и** `getWarningMessages()`. Не вызывай `$order->save()` внутри `OnSaleOrderSaved`.
