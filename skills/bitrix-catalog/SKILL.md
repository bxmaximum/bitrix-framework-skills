# Торговый каталог (`catalog`)

Baseline: main 23.0+ · Verified: catalog 26.500.0, main 26.1000.0

Перед PHP-кодом прочитай `bitrix-framework`, если ещё не читал его в этой задаче.

ID товара совпадает с ID элемента инфоблока. Загрузи `iblock` + `catalog`. Корзина, заказы, оплата: `bitrix-sale`; элементы и свойства: `bitrix-iblocks`.

| Задача | Читать |
| --- | --- |
| Создание каталога, товары, типы и предложения SKU | `rules/products.md` |
| Типы цен, запись цен, НДС, права REST | `rules/prices.md` |
| Остатки, складские документы, фильтр доступных складов | `rules/stores.md` |

Открой только нужный файл правил.

## Общие правила

- Записывай товары через `Model\Product`, цены через `Model\Price`; прямой ORM обходит пересчёты.
- Проверяй каждый `Result`; базовый тип цены находи через `GroupTable::getBasePriceTypeId()`.
- В корзину передавай ID предложения, не родителя SKU.
- Для ограниченного пользователя применяй фильтр складских прав, читай пакетами.
