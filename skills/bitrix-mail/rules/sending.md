# Sending

## Queue (default)

```php
use Bitrix\Main\Mail\Event;

$result = Event::send([
    'EVENT_NAME' => 'VENDOR_ORDER_READY',
    'LID' => 's1',                              // site id
    'C_FIELDS' => ['EMAIL' => $email, 'NAME' => $name, 'ORDER_ID' => (string)$orderId],
    'LANGUAGE_ID' => 'ru',                      // optional template filter
    'DUPLICATE' => 'N',                         // 'Y' (DB default) adds option main:all_bcc to BCC
    'FILE' => [$fileId],                        // b_file ids; paths/URLs are copied into b_file
]);
if (!$result->isSuccess())
{
    // cancelled by OnBeforeEventAdd or insert failed
}
```

- The call returns `ORM\Data\AddResult` for the `b_event` row, which means "queued", not "sent". Delivery and statuses: `rules/hooks-testing.md`.
- Queued `FILE` ids are read at send time, so don't delete them right after `send()`. Files copied from paths are deleted by an agent after the `b_event` row is purged.
- Wrapper (compat only): `CEvent::Send($event, $lid, $arFields, $Duplicate = 'Y', $message_id = '', $files = [], $languageId = '')` → id or `false`. `$lid` may be an array of sites; `$message_id` forces one template.

## Immediate

```php
$status = Event::sendImmediate([
    'EVENT_NAME' => 'VENDOR_ORDER_READY',
    'LID' => 's1',
    'C_FIELDS' => ['EMAIL' => $email, 'NAME' => $name, 'ORDER_ID' => (string)$orderId],
    'LANGUAGE_ID' => 'ru',                      // read without isset: always pass it
    'DUPLICATE' => 'N',
    'FILE' => [$fileId],                        // numeric b_file ids only; paths are ignored here
]);
if ($status !== Event::SEND_RESULT_SUCCESS) { /* PARTLY 'P', ERROR 'F', TEMPLATE_NOT_FOUND '0', NONE 'N' = cancelled */ }
```

- Sends in the current request (SMTP time included) and nothing is logged to `b_event`. Use it in CLI scripts, when the user must see a failure, or when you need a sender identity.
- `FILES_CONTENT` (immediate only) attaches generated bytes: `[['NAME' => 'invite.ics', 'CONTENT' => $ics, 'CONTENT_TYPE' => 'text/calendar', 'ID' => 'ics1', 'CHARSET' => 'UTF-8', 'METHOD' => 'REQUEST']]`. Pass all six keys (`METHOD` may be `null`).
- Wrapper: `CEvent::SendImmediate($event, $lid, $arFields, $Duplicate = 'Y', $message_id = '', $files = [], $languageId = '', array $filesContent = [])` → status or `false` when cancelled.

## Sender identity — Since main 26.800

```php
use Bitrix\Main\Mail\Sender\Identity;

$status = Event::sendImmediate($data, Identity::fromSender($senderId));   // b_main_mail_sender.ID
// Identity::fromMailbox($mailboxId) / fromMailboxAndSender($mailboxId, $senderId): mailboxes of module mail
```

- Also `CEvent::SendImmediate(..., $filesContent, $senderIdentity, $context)`. The queue keeps neither identity nor context, so `Event::send()` has no such parameter.
- With an identity, `From` must equal the sender's address, or sending fails with `MAIL_SENDER_ADDRESS_MISMATCH`.
- On older kernels, set the `From` address and let the SMTP sender be picked by address.

## Direct message without a template

```php
use Bitrix\Main\Mail\Mail;

$result = Mail::sendResult([                   // Since main 26.800; older: Mail::send() → bool
    'TO' => $to,
    'SUBJECT' => $subject,
    'BODY' => $html,
    'HEADER' => ['From' => $from, 'Reply-To' => $replyTo],
    'CHARSET' => 'UTF-8',
    'CONTENT_TYPE' => 'html',                  // or 'text'
    'ATTACHMENT' => [[
        'ID' => 'report1',                     // Content-ID, required
        'NAME' => 'report.pdf',
        'CONTENT_TYPE' => 'application/pdf',
        'PATH' => $absPath,                    // or 'CONTENT' => $bytes
    ]],
]);
foreach ($result->getErrors() as $error)
{
    // MAIL_SEND_CANCELED, MAIL_SEND_NOT_ALLOWED (no recipient left after blacklist),
    // MAIL_SEND_FAILED, MAIL_SENDER_ADDRESS_MISMATCH, or a handler's own error
}
```

- Required keys: `TO`, `SUBJECT`, `BODY`, `HEADER` (array), `CHARSET`, `CONTENT_TYPE`. There is no queue, no template and no `b_event` row. `OnBeforeMailSend` still fires.
- Sender: `'CONTEXT' => (new \Bitrix\Main\Mail\Context())->setSenderIdentity(Identity::fromSender($senderId))`. `->setAutomaticCustomSmtpEnabled(false)` skips the per-sender SMTP lookup (Since main 26.800).
- An attachment that pushes the total (base64) size over option `main:max_file_size` is replaced with a `.txt` note.

## Which SMTP is used

1. With `smtp.enabled === true` in `.settings.php`, a per-sender SMTP connection (`b_main_mail_sender`) is picked by the `From` address or by identity.
2. Otherwise the default server from the same section is used (`host` and `login` both set).
3. Otherwise PHP `mail()`, or `custom_mail()` if you defined it.

Config keys: `bitrix-settings`. **Since main 26.800**, when several senders share one address, the public one wins, else the oldest. Before 26.800 the newest won. Ambiguity is logged as `MAIL_SENDER_AMBIGUOUS`. Keep one sender per address or send with an identity.
